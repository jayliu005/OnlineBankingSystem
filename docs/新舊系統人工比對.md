## 錯誤與權限比對

- 未登入存取受保護 API：新系統回傳 `401`，與舊系統導向登入流程一致。
- 他人帳戶操作：新系統回傳 `404`，不洩漏帳戶歸屬。
- 錯誤 PIN、餘額不足、同帳戶轉帳及超過金額上限：新系統回傳 `400`，且資料不異動。
- 個人資料非法姓名、Gender、Email、Phone：新系統回傳 `400` 並提供欄位錯誤。
- 交易日期倒置：新系統回傳 `400`；日期範圍包含結束日。

## 畫面比對與已知差異

- Vue 已沿用舊專案 `general.xhtml`、各功能 XHTML、`screen.css` 與必要圖片資源；欄位順序、英文文案、綠色 fieldset、按鈕配置及成功摘要維持一致。
- 品牌名稱由舊版 `Green's Online Banking System` 統一改為需求指定的 `OnlineBankingSystem`，屬刻意的品牌差異。
- JSF／PrimeFaces inplace editor、calendar、dataTable 與 Web Flow state 改為 Vue route、HTML form、REST API 與元件狀態，屬技術實作差異。
- 舊系統使用 port `8080` 與 `/onlinebanking` context path；新系統使用 Vite `5173`、Spring Boot `18080` 及 `/api` REST path，屬部署差異。
- 舊系統未登入入口使用 server redirect；新系統由 Vue Router guard 處理，使用者可見結果一致。
