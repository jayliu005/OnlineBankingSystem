# 舊版前端資源

本目錄資源複製自唯讀舊專案
`onlinebanking/onlinebanking/src/main/webapp/resources/images/`，用於讓 Vue 畫面維持舊系統的視覺與操作配置。

- `bank.png`、`noise.png`、`gray_texture.jpg`：共用頁首、背景與表單紋理。
- `addfile.png`、`withdraw.png`、`deposit.png`、`transfer.png`、`history.png`：帳戶首頁功能選單。
- `userinfo.png`、`logout.png`：帳戶首頁使用者操作。
- `succeed.png`、`home.png`：建立帳戶成功提示與返回帳戶首頁操作。

這些檔案是舊資源的未修改副本；不得反向修改舊專案。
